# Gran Consiglio

Marketplace di box a sorpresa per piante — modello "Too Good To Go" applicato ai vivai/negozi di piante:
i venditori pubblicano box a sorpresa con piante in esubero a prezzo scontato, i clienti le prenotano
e le ritirano in negozio in una fascia oraria.

Vedi [`docs/implementation-plan.md`](docs/implementation-plan.md) per il piano completo e
[`PROGRESS.md`](PROGRESS.md) per lo stato di avanzamento.

## Struttura

- [`backend/`](backend/README.md) — API (Node.js + Express + Prisma + MySQL)
- `mobile/` — app React Native/Expo (non ancora scaffoldata)
